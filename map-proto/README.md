# 물류기지 맵 프로토타입

폭파 미션용 A/B 목표 지점이 있는 소규모 FPS 맵의 블록아웃(형태 잡기) 프로토타입입니다. 총격 없이 1인칭으로 맵을 돌아다니며 동선, 시야, 고저차를 확인하는 용도입니다.

같은 맵이 봇 대전 게임 `fps/index.html`(보급기지 작전)에도 `물류기지`라는 이름으로 들어가 있습니다. 게임 쪽은 이 파일의 `MAP_CONFIG`를 복사해 `DEPOT`라는 이름으로 쓰므로, 맵을 고치면 두 곳에 같이 반영해야 합니다.

- three.js(0.160)를 import map으로 CDN에서 불러옵니다. 빌드 도구는 없습니다.
- 모든 맵 요소는 three.js 기본 도형(BoxGeometry, PlaneGeometry, 파이프와 탱크만 CylinderGeometry)과 단색 MeshStandardMaterial로 만들었습니다. 외부 텍스처, 모델, 맵 파일은 쓰지 않았습니다. 표지판과 바닥 글자는 코드에서 canvas로 그린 글씨입니다.
- 구조는 "긴 야외 라인 + 짧은 실내 라인 + 중앙 2층 우회로 + A/B 목표 지점"이라는 전투 구조만 참고해 새로 설계했습니다. 특정 게임 맵의 명칭, 로고, 외형은 쓰지 않았습니다.

## 실행

브라우저는 파일을 직접 열 때(`file://`) 모듈 스크립트를 막기 때문에 간단한 로컬 서버로 엽니다.

```bash
cd map-proto
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`npx serve` 같은 다른 정적 서버도 됩니다. 처음 열 때 인터넷 연결이 필요합니다(three.js CDN). 파일을 직접 열면 화면에 서버로 여는 방법이 안내됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 시점 회전 (화면이나 `클릭해서 시작`을 누르면 Pointer Lock) |
| Shift | 달리기 |
| Space | 점프 |
| R | 시작 위치로 리스폰 |
| M | 미니맵 크게 / 작게 |
| Esc | 마우스 고정 풀기 (안내 화면으로 돌아감) |

안내 화면에서 블루 스폰과 레드 스폰 중 시작 위치를 고를 수 있습니다. 화면 위에 현재 구역 이름, 오른쪽 위에 미니맵(내 위치와 보는 방향), 왼쪽 아래에 좌표(x, z, y)가 나옵니다. 좌표는 MAP_CONFIG를 고칠 때 참고하면 됩니다.

## 파일 구조

```
map-proto/
├── index.html   화면 구성, import map, 안내 오버레이, file:// 실행 안내
├── style.css    HUD(구역 이름, 미니맵, 좌표), 안내 오버레이
├── main.js      MAP_CONFIG, 맵 생성, 이동과 충돌, 미니맵, 구역 표시
└── README.md
```

`main.js`의 구성:

1. `MAP_CONFIG`: 맵 크기, 플레이어 수치, 스폰, 색, 구역, 모든 오브젝트
2. 대칭 처리: `west`(블루 쪽 절반)를 x = 0 기준으로 뒤집어 레드 쪽을 만듦
3. 렌더러, 조명(Hemisphere, Ambient, 그림자 있는 Directional), 안개
4. 맵 생성: `addWall`(문과 창문 구멍이 있는 벽), `addBox`, `addStairs`(계단 한 칸마다 Box), 파이프, 탱크, 바닥 색, 표지판, 실내 조명
5. 플레이어: 축별 이동과 AABB 충돌, 0.45m 이하 턱은 자동으로 올라섬(계단), 중력, 착지, 천장, 바닥 아래로 떨어지면 리스폰
6. HUD: 구역 판정, 미니맵(벽과 엄폐물을 위에서 본 모습, 지붕은 빼고 그림)

## 좌표계

- 단위는 m. x는 서쪽(-, 블루)에서 동쪽(+, 레드), z는 북쪽(-)에서 남쪽(+), y는 위쪽입니다.
- 맵 전체: x -64 ~ 64, z -44 ~ 44 (128m × 88m), 바깥 벽 높이 8m
- 미니맵은 북쪽이 위입니다.

## 목표 지점 진입로

- **A**: 양쪽 짧은 길(실내 복도) 2개, 중앙 건물에서 남쪽 큰 문, 양쪽 북쪽 통로에서 옆문 2개. 우회는 중앙 건물 1층이나 2층 보행로를 지나 반대편으로 갑니다.
- **B**: 벽으로 둘러싸여 있고, 양쪽에서 B 연결 통로, 긴 골목, 뒤쪽 우회로로 들어오는 입구 3개씩과 중앙 건물 남쪽 문(B Link), 2층 발코니에서 바깥 계단. 우회는 B 뒤쪽 좁은 길(B Flank)로 반대편 긴 길까지 이어집니다.

블루와 레드는 맵을 정확히 좌우로 뒤집은 배치라서 각 스폰에서 A, B까지의 거리가 같습니다. 테스트에서 걸어서 걸린 시간(달리기 없이)은 다음과 같고 두 팀이 같았습니다.

| 경로 | 시간 |
| --- | --- |
| 스폰 → 북쪽 통로 → A 옆문 | 약 15초 |
| 스폰 → 짧은 길 → A | 약 20초 |
| 스폰 → 가운데 통로 → 중앙 건물 1층 → A 큰 문 | 약 20초 |
| 스폰 → 남쪽 통로 → B 연결 통로 → B | 약 17초 |
| 스폰 → 긴 골목 → B | 약 21초 |
| 스폰 → 긴 골목 → B 뒤 우회로 → B | 약 24초 |

## 맵 고치기

`main.js` 맨 위의 `MAP_CONFIG`만 고치면 됩니다.

```js
// 상자 하나: 모서리 범위로 적음
{ x: [-3, -1], z: [-32, -30], y: [0, 2], mat: 'crate' }

// 문과 창문이 있는 벽: axis 'x'는 x = at 위치에서 z 방향으로, axis 'z'는 z = at 위치에서 x 방향으로 뻗음
// open: [[시작, 끝, 아래 높이, 위 높이]]
{ axis: 'z', at: -18, from: -16, to: 16, h: 9, mat: 'warehouse', open: [[-4, 4, 0, 4.5]] }

// 계단: dir은 올라가는 방향
{ x: [-11.5, -3.5], z: [-11.75, -9.75], rise: 4, steps: 16, dir: '+x', mat: 'concreteDark' }
```

- `center`: 한 번만 만드는 것(A 창고, 중앙 건물, B 가운데 등)
- `west`: 블루 쪽 절반. 레드 쪽에 좌우 대칭으로 한 번 더 만들어지고, `mirrorMat`에 따라 파란색은 빨간색으로 바뀝니다.
- `zones`: 화면 위에 표시되는 구역. 위에 있는 것이 먼저 판정됩니다.
- `kind: 'roof'`는 미니맵에 그리지 않고, `kind: 'container'`는 컨테이너 무늬가 붙습니다. `hidden: true`는 보이지 않는 충돌 상자입니다(파이프 묶음).

브라우저 콘솔에서 `player`, `MAP_CONFIG`, `COLLIDERS`, `respawn()`을 바로 쓸 수 있습니다.
