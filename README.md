# 블록 월드

브라우저에서 바로 하는 블록 샌드박스 게임입니다. 블록을 부수고 쌓아서 세상을 만들 수 있습니다. `index.html` 파일 하나로 되어 있고, 3D 엔진은 three.js(r128)를 CDN에서 불러옵니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. PC와 휴대폰 모두 동작합니다. 인터넷 연결이 필요합니다(three.js와 글꼴).

## 조작

**PC**

| 키 | 동작 |
| --- | --- |
| W A S D / 방향키 | 이동 |
| 마우스 | 둘러보기 (화면을 클릭하면 마우스가 고정됩니다) |
| 왼쪽 클릭 | 블록 부수기 (누르고 있으면 계속) |
| 오른쪽 클릭 | 블록 놓기 |
| 스페이스 | 점프, 비행 중에는 위로 |
| Shift | 비행 중 아래로 |
| F | 비행 켜기/끄기 |
| 1~9, 마우스 휠 | 블록 고르기 |
| Esc | 메뉴 |

**휴대폰**

- 왼쪽 조이스틱으로 이동하고, 화면을 드래그해서 둘러봅니다.
- 화면을 탭하면 가운데 조준점의 블록을 부수거나 놓습니다. `부수기/놓기` 버튼으로 바꾸고, 아래 블록을 고르면 놓기로 바뀝니다.
- `점프`, `비행` 버튼이 있습니다. 비행 중에는 점프 버튼을 누르고 있으면 올라갑니다.

## 세계

- 128×128×64 크기의 세계가 무작위로 만들어집니다. 언덕, 눈 덮인 산, 바다와 모래사장, 나무가 있습니다.
- 블록 12종: 잔디, 흙, 돌, 모래, 통나무, 나뭇잎, 나무 판자, 유리, 벽돌, 물, 조약돌, 눈
- 낮과 밤이 8분마다 한 바퀴 돕니다.
- 물에 들어가면 헤엄칠 수 있습니다.
- 바꾼 블록과 위치는 브라우저(localStorage)에 저장됩니다. 다른 기기에서는 이어지지 않고, 사이트 데이터를 지우면 초기화됩니다. 메뉴의 `새 세계 만들기`로 새 세계를 시작할 수 있습니다.

블록 그림은 모두 코드로 직접 그렸고, 다른 게임의 그림이나 이름은 쓰지 않았습니다.

# Jammini_FPS_1.0

봇과 싸우는 1인칭 총게임입니다. 나와 아군 봇 4명(블루)이 레드 팀 봇 5명과 팀 데스매치를 합니다. 먼저 목표 킬을 내거나 제한 시간이 끝났을 때 앞선 팀이 이깁니다. 목표 킬(20, 30, 40, 60, 80, 100)과 제한 시간(3, 5, 10, 15분)은 메인 메뉴에서 정합니다(기본 40킬, 5분).

- **맵 3개** (메인 메뉴의 `맵`에서 선택, 고르면 페이지가 새로 열리며 바뀜). 모두 블루는 서쪽, 레드는 동쪽 스폰이고 좌우 대칭이라 공평합니다. 봇도 계단으로 2층을 오갑니다.
  - **물류기지** (128m × 88m): 짧은 실내 복도(→ A), 스폰과 중앙 건물 사이의 **창고 골목**(작은 건물, 컨테이너, 상자, 방벽), 2층 중앙 건물(북쪽 보행로, 남쪽 발코니, 바깥 계단), 실내 창고 A, 벽으로 둘러싼 야외 설비장 B와 B 뒤 우회로가 있습니다. 레이더 아래에 지금 있는 구역 이름(A Site, Central Hall 2F 등)이 나옵니다. 창고 골목 배치는 메인 메뉴의 `창고 배치`에서 `매번 무작위` 또는 고정된 `배치 1~3` 중에 고를 수 있습니다.
  - **콜로세움** (76m × 56m): 가로 60m, 세로 40m의 타원형 경기장. 가운데 조각상, 부러진 기둥, 쓰러진 기둥, 나무 바리케이드, 두 단짜리 단상이 엄폐물입니다. 경기장 둘레의 벽에는 문이 6개(양 팀 정문 2, 옆문 4) 있고, 그 바깥으로 지붕 덮인 **회랑**이 한 바퀴 돌며 기둥이 회랑을 칸칸이 나눕니다. 회랑 지붕은 **관중석 통로**(2층, 높이 4m)라서 계단 4개로 올라가 낮은 난간 너머로 경기장을 내려다볼 수 있습니다. 각 팀은 회랑의 자기 쪽 끝에서 시작하고, 정문 앞에는 시야를 막는 벽이 있습니다.
  - **사막** (104m × 72m): 흙벽돌 집 16채가 있는 사막 마을. 집마다 문과 창문이 있고, 8채는 북쪽 바깥 계단으로 평평한 지붕(2층, 높이 3.5m)에 올라갈 수 있습니다. 가운데에 오벨리스크 광장, 우물, 시장 좌판과 천막, 북쪽에 기둥 늘어선 시장 회랑, 남쪽에 폐허, 곳곳에 모래 언덕, 야자수, 상자, 모래주머니가 있습니다. 스폰은 돌담으로 둘러싼 야영지입니다.
- **친구와 온라인** (메인 메뉴 → `친구와 온라인으로 하기`): 계정이나 우리 서버 없이 브라우저끼리 직접 연결합니다.
  - 방장이 `방 만들기`를 누르면 4글자 방 코드와 `초대 링크 복사` 버튼이 나오고(링크를 누른 친구는 바로 방에 들어옵니다), 친구는 같은 게임 주소를 열어 코드를 입력합니다. 맵은 방을 만들기 전에 메인 메뉴에서 고르고, 친구의 게임은 방장과 같은 맵(물류기지는 창고 골목 배치까지)으로 자동으로 다시 열린 뒤 다시 접속합니다.
  - 대기실에서 방장이 **협동**(친구가 같은 팀) 또는 **대결**(친구가 상대 팀)을 고릅니다. 친구는 봇 한 자리를 대신해서 5 대 5가 유지됩니다. 무기는 각자 대기실의 `무기 선택`에서 고릅니다.
  - 방장의 게임이 봇, 점수, 부활, 수류탄 피해를 맡고, 친구는 자기 움직임과 사격을 직접 처리해 맞춘 결과를 방장에게 보냅니다. 위치와 시선은 1초에 약 20번 주고받고, 받은 위치를 0.12초 늦춰 두 업데이트 사이를 이어 그려서 인터넷이 고르지 않아도 상대가 부드럽게 움직입니다. 게임 중 점수판 아래에 핑(ms)과 연결 방식(직접 연결 / 중계 서버 경유)이 나옵니다. 친구가 나가면 그 자리는 봇이 이어받습니다. 온라인 중에는 일시정지 화면을 열어도 게임이 멈추지 않습니다.
  - 방 찾기에는 무료 공개 중개 서비스(PeerJS)를 쓰고, 연결된 뒤에는 둘이 직접 주고받습니다. 직접 연결이 막힌 네트워크에서는 PeerJS의 공개 중계 서버를 거칩니다. 회사·학교 망 등 일부 네트워크에서는 연결이 안 될 수 있습니다.
  - **그래픽 가속**: 브라우저의 그래픽 가속이 꺼져 있으면(메뉴 맨 아래에 `Microsoft Basic Render Driver` 등이 보이고 빨간 경고가 뜸) 그래픽카드 대신 CPU로 그려서 20~30 FPS 정도밖에 안 나옵니다. 평소 브라우저 설정을 바꾸고 싶지 않다면 Windows에서 `fps/Jammini_FPS_1.0.bat`(게임 주소의 `Jammini_FPS_1.0.bat`)을 받아 실행하세요. 별도 프로필의 Chrome(없으면 Edge) 앱 창으로 게임만 열고, 그 창에서만 그래픽카드를 씁니다.
  - **PC 버전 (.exe)**: https://github.com/Hany36/Hany36/releases/tag/desktop (Jammini_FPS_1.0.exe) — 설치 없이 실행되는 Windows 프로그램(`desktop/`, Electron)입니다. 브라우저 설정과 상관없이 그래픽카드를 쓰고, 열 때마다 게임 주소에서 최신 버전을 불러옵니다(F11 전체 화면, F5 새로고침, Ctrl+W로 꺼지지 않음). exe는 자동으로 다시 만들지 않고, 저장소의 Actions → `PC 버전 빌드` → `Run workflow`를 눌렀을 때만 GitHub Actions(`.github/workflows/desktop.yml`)가 빌드해서 `desktop` 릴리스에 올립니다. 아이콘은 `desktop/build/icon.png`(픽셀 아트 소총)입니다.
  - 친구가 열 주소: GitHub Pages를 켜면 `https://hany36.github.io/Hany36/fps/` 로 열 수 있습니다(저장소 Settings → Pages → Source: Deploy from a branch → 브랜치 `claude/jolly-pascal-dtmrqz`, 폴더 `/ (root)` → Save).
- **그래픽**: 그림자, 사실적인 재질(콘크리트, 골함석 벽, 벽돌, 아스팔트, 나무 상자), 위장복과 방탄조끼, 마스크를 쓴 병사, 레드닷 조준경이 달린 소총. 그래픽 품질은 자동(기본), 낮음, 보통, 높음 중에서 고를 수 있습니다. 자동은 게임 중 초당 프레임을 재서 느리면 해상도·그림자·조명을 단계적으로 낮춥니다. 큰 모니터에서도 한 화면에 그리는 픽셀 수에 상한을 둬서(보통 기준 약 200만 픽셀) 노트북 화면보다 몇 배 무거워지지 않습니다. 설정의 `FPS 표시`를 켜면 점수판 아래에 초당 프레임과 그리는 해상도가 나옵니다. 컴퓨터가 느려 화면이 끊겨도 게임 속도는 실제 시간대로 흐릅니다(한 프레임이 0.1초를 넘을 때만 느려집니다).
- **무기 선택 화면**: 전투 시작 전에 카운터스트라이크처럼 무기를 고릅니다. 주무기 4종(돌격소총, 기관단총, 산탄총, 저격총), 보조무기 2종(권총, 리볼버), 장비 1개(수류탄 2개 또는 받는 피해를 30% 줄이는 방탄조끼). 카드마다 피해, 연사, 사거리, 기동 막대가 있고 숫자 키 1~8로도 고를 수 있습니다. 게임 중에는 B 키나 일시정지 화면의 `무기 변경`으로 열고, 다음 부활부터 적용됩니다. 칼은 항상 들고 있습니다.
- **산탄총**: 한 발에 산탄 9개(한 알 23 피해)가 퍼지고, 멀수록 피해가 줄어듭니다. 6m 안에서는 한 방, 10m에서 약 65% 확률로 한 방입니다.
- **경기 종료 연출**: 승부가 나면 화면이 느려지고(슬로 모션 약 3초), 카메라가 뒤로 빠지며 위로 올라가고, `승리 / VICTORY`, `패배 / DEFEAT`, `무승부 / DRAW` 문구가 크게 떨어지며 효과음이 납니다. 이기면 따뜻한 색, 지면 흑백에 가까운 색으로 화면이 바뀝니다. 이기면 낮고 무거운 금관 합주가 "둔… 둔" 두 번 울리고 큰북과 팀파니가 받쳐 주는 짧은 음악(약 3초), 지면 낮은 현악과 금관의 느린 단조 음악이 나옵니다(모두 코드로 합성). 그다음 결과 화면에 MVP, 내 킬·데스·헤드샷·명중률, 양 팀 점수판이 나옵니다.
- **조준**: 소총과 권총은 정조준하면 조준경이 화면 가운데로 오고, 빨간 조준점이 표시됩니다. 저격총은 스코프 화면으로 바뀝니다.
- **스캐빈저**: 누가 죽든 그 자리에 총과 탄약 상자가 떨어집니다(30초 유지). 가까이 가면 들고 있는 주무기와 보조무기의 탄약, 수류탄 +1을 줍습니다. 탄약이 가득 차 있으면 줍지 않고 남겨 둡니다.
- **설정** (메뉴와 일시정지 화면): 봇 난이도, 조준·앉기·기울이기 방식(누르고 있기 / 눌러서 켜고 끄기), 마우스 감도, 정조준 감도(소총·기관단총·산탄총·권총), 저격 감도(저격총 스코프), 음량(0~100%, 0이면 소리 끔), 그래픽 품질. 설정은 브라우저에 저장됩니다.
- **봇**: 맵의 길을 찾아 움직이고, 적을 보면 반응 시간 뒤에 좌우로 움직이며 끊어 쏩니다. 멀리 있는 적에게는 길을 따라 다가가고, 벽에 막혀 제자리걸음을 하면 옆으로 비켜서 길을 다시 찾습니다. 난이도에 따라 반응 속도와 정확도가 다릅니다.
- **화면**: 점수와 남은 시간, 레이더(아군은 항상, 적은 발견했을 때 표시), 킬 로그, 체력, 탄약, 맞춘 표시, 피격 방향, Tab 점수판
- **달리기와 슬라이딩**: Shift를 누르고 앞으로 가면 달립니다(걷기보다 약 40% 빠르고, 총을 내리고 시야가 조금 넓어집니다). 달리는 중에 정조준하거나 쏘면(좌클릭) 그쪽이 우선이라 달리기가 풀리고, 버튼을 떼면 다시 달립니다. 달리는 중에 C를 누르면 0.8초 동안 약 6m 미끄러지며 속도가 걷기·달리기 속도로 자연스럽게 이어지고, 시점도 부드럽게 올라오며 다시 일어섭니다(C를 계속 누르고 있어도 앉지 않고, 다시 누르면 앉습니다). 슬라이딩이 끝난 뒤 약 1.2초 동안은 다시 슬라이딩할 수 없습니다.
- **기울이기**: Q는 왼쪽, E는 오른쪽으로 몸을 기울여 엄폐물 옆으로 머리만 내밀 수 있습니다. 벽에 붙어 있으면 머리가 벽을 뚫지 않게 덜 기울어지고, 기울이는 동안에는 천천히 움직입니다.
- **경기 끝 하이라이트 (킬캠)**: 승부가 나면 승리/패배 연출 뒤에 하이라이트를 다시 보여 줍니다. 경기 중 멋진 장면(4초 안에 이어진 3연속 킬 이상, 두 발 모두 헤드샷인 더블 킬, 40m 이상 헤드샷)이 있었으면 그중 점수가 가장 높은 `BEST PLAY`를, 없으면 이긴 팀이 승부를 결정지은 `FINAL KILL`을 보여 줍니다(승부가 난 뒤의 킬은 제외). 킬러의 1인칭 시점으로 시작해, 총이면 총알을 따라 날아가는 총알 캠(산탄총은 퍼지는 산탄, 저격총은 길고 굵은 탄), 칼은 가까운 슬로 모션 베기, 수류탄은 날아가는 수류탄을 따라가다 폭발로 이어지고, 마지막에 쓰러지는 상대 주위를 카메라가 돕니다. Space, Enter, 클릭으로 건너뛸 수 있습니다.

- **채팅**: 게임 중 Enter로 채팅 창을 열고, 입력한 뒤 Enter로 보냅니다(빈 채로 Enter 또는 Esc는 닫기). 메시지는 화면 왼쪽 아래에 10초 동안 보입니다. 온라인 대기실에도 채팅 칸이 있습니다. 온라인에서는 친구에게 전해지고, 봇전에서는 나에게만 보입니다.
